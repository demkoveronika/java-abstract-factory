# Калькулятор меблевих фасадів

**Варіант №3**

Консольна програма мовою Java для розрахунку вартості меблевих фасадів із використанням патерна проєктування Abstract Factory (Абстрактна фабрика).

## Мета роботи

Ознайомитися з патерном проєктування Abstract Factory та реалізувати його для створення сімейств об'єктів різних типів.

## Опис програми

Програма дозволяє розраховувати вартість меблевих фасадів залежно від матеріалу, типу та площі.

Підтримуються три матеріали:

- Плівка
- Фарба
- Пластик

Для кожного матеріалу доступні два типи фасадів:

- Суцільний фасад
- Фасад-вітрина (з отвором для скла)

## Функціональні можливості

- Вибір матеріалу фасадів.
- Вибір типу кожного фасаду.
- Введення кількості фасадів.
- Введення площі кожного фасаду.
- Розрахунок вартості кожного фасаду.
- Обчислення загальної вартості замовлення.
- Перевірка правильності введених числових значень.
- Заборона додавання фасадів різних матеріалів до одного замовлення.

## Використані технології

- Java
- Об'єктно-орієнтоване програмування (ООП)
- Патерн Abstract Factory
- Visual Studio Code
- Git та GitHub

## Структура проєкту

- `Facade.java` — абстрактний клас фасаду.
- `SolidFacade.java` — клас суцільного фасаду.
- `GlassFacade.java` — клас фасаду-вітрини.
- `FacadeFactory.java` — інтерфейс абстрактної фабрики.
- `FilmFactory.java` — фабрика плівкових фасадів.
- `PaintFactory.java` — фабрика фарбованих фасадів.
- `PlasticFactory.java` — фабрика пластикових фасадів.
- `Order.java` — клас для формування замовлення та розрахунку загальної вартості.
- `Main.java` — головний клас програми, який забезпечує взаємодію з користувачем.

## Використання патерна Abstract Factory

Патерн Abstract Factory дозволяє створювати сімейства пов'язаних об'єктів без безпосередньої залежності від їхніх конкретних класів.

У програмі інтерфейс `FacadeFactory` визначає два методи:

- `createSolidFacade()` — створення суцільного фасаду.
- `createGlassFacade()` — створення фасаду-вітрини.

Класи `FilmFactory`, `PaintFactory` та `PlasticFactory` реалізують цей інтерфейс і створюють фасади відповідного матеріалу.

Завдяки цьому можна змінювати матеріал фасадів, не змінюючи загальну логіку створення замовлення.

## Запуск програми

1. Відкрити папку проєкту у Visual Studio Code.
2. Відкрити термінал.
3. Скомпілювати Java-файли командою:

   javac -encoding UTF-8 \*.java

4. Запустити програму командою:

   java Main

5. Вибрати матеріал, кількість фасадів, їхні типи та площі.
6. Переглянути результат розрахунку.

## Висновок

У ході виконання лабораторної роботи було розроблено консольну програму мовою Java для розрахунку вартості меблевих фасадів.

Було застосовано патерн Abstract Factory, який забезпечує створення різних типів фасадів залежно від вибраного матеріалу.

Програма підтримує формування замовлень, розрахунок вартості та перевірку коректності введених даних.
